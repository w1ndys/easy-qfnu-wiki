# easy-qfnu-wiki

曲阜师范大学校园知识。正文在本仓库的 Markdown，不使用 GitHub Wiki。

网页由这些 Markdown 用 VitePress 构建。合并到 `main` 后由 GitHub Actions 发布到：

https://w1ndys.github.io/easy-qfnu-wiki/

当前分组：

- `life/`：校园生活，现有 `life/express.md`（快递问题）、`life/water-card.md`（水卡绑定）
- `about/`：关于本站，现有 `about/contribute.md`（提交收录）
- `example/`：示例分组，`example/sample.md` 用来看页面怎么写

本地预览：

```bash
npm ci
npm run dev
```

文章仍在整理，还不是完整知识库。这里不是学校官网。
